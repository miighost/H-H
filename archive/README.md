# Retained historical UI sources

These exact older UI files are retained for reference, not mounted as production modules. The previous demonstrations stored sample records in the browser and must not be confused with real workflows. Their original component entry points now open ConnectedPortal. Legacy URL/hash aliases in src/App.tsx route to the corresponding persistent production module. A document describing a feature is not evidence of implemented or deployed code.

The approved public landing page and official assets are retained. The old CEO source in private/ceo-desktop.html is reference artwork; public users cannot fetch it from the deployed static root. Current CEO navigation preserves five top-level folders, with real child records instead of browser-local seeded data.
